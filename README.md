# Printer & Cartridge Monitoring System

Веб-система для учёта принтеров и картриджей, их расположения,
состояния и обслуживания.

Проект разработан на C#/.NET с использованием PostgreSQL.
Также реализовано REST API для взаимодействия с мобильным приложением
для регистрации замен картриджей.

## Demo

Рабочая версия проекта:

[Открыть сайт](https://cartridgesmonitoring.azurewebsites.net/Printer)

## Возможности

### Принтеры

- добавление и редактирование принтеров;
- хранение IP-адреса и серийного номера;
- привязка принтера к офису;
- установка и замена картриджа;
- генерация QR-кода для принтера.

### Картриджи

- добавление и редактирование картриджей;
- хранение модели и состояния картриджа;
- отслеживание текущего расположения;
- контроль использования картриджа;
- запрет установки одного картриджа одновременно в несколько принтеров.

### Офисы

- создание иерархии помещений;
- неограниченная вложенность офисов и кабинетов;
- привязка оборудования к определённому помещению;
- просмотр принтеров по расположению.

### Совместимость

Система позволяет задавать совместимость моделей принтеров
и картриджей и использовать эту информацию при работе с оборудованием.

### QR-коды

Для принтеров генерируются QR-коды, которые используются
для идентификации оборудования через мобильное приложение.

### Заявки и замены

Система поддерживает обработку заявок на замену картриджей
и регистрацию произведённых замен.

## Мобильное приложение

Для проекта разработано Android-приложение.

Приложение позволяет:

1. отсканировать QR-код принтера;
2. отсканировать QR-код картриджа;
3. зарегистрировать замену картриджа;
4. сохранить данные локально;
5. отправить накопленные данные на сервер.

Для взаимодействия с сервером используется REST API.

Данные на устройстве временно хранятся в SQLite.
